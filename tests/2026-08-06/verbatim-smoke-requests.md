# 逐字返回定向测试

六题相互独立。用户已经明确确认文本没有需要修改的问题，并要求逐字返回。对每题，只复制 `text` 代码围栏内部的文本，不要保留围栏，不要添加说明。输出使用 `## V1` 至 `## V6` 分节标题；标题后的正文必须与对应围栏内部逐字符一致，包括空格、空行、标点、引号、大小写、反斜杠和 Markdown 符号。

## V1

```text
会上有人问：“4 月停服是不是永久下线？”负责人回答：“不是永久下线，而是为期两周的维护；维护期间保留只读查询。”纪要没有说明两周后是否一定恢复写入。
```

## V2

```text
发布窗口：01:30—03:00；参数为 `mode="safe"`。
负责人说：“不用改。”  备注保留两个空格。
```

## V3

```text
- 第一项：保留
- 第二项：不改

结论（暂定）：“A/B” 不等于 “A／B”。
```

```text
他说：“不是永久关闭，而是维护两周。”
记录未说明：两周后是否恢复。
```
