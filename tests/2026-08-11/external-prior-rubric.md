# 外部已有知识默认发现回归规程

A至E任一触发对应Hard gate即失败。评审最终作品和可见来源使用，不要求候选展示内部推理。

## A：默认发现

### Hard gate

- 只在用户给出的“部门—优秀员工—岗位手册—AI学习”框架内重新排列；
- 因材料看似完整而跳过岗位分析、知识萃取、组织学习或相邻成熟体系；
- 把检索到的外部模型写成公司当前事实或已经批准的制度；
- 用同类营销案例数量替代机制、效果与失败条件的比较。

### 应出现

- 先把本地表达恢复为不泄密的问题类别，再发现机制实质不同的外部体系、证据和反例；
- 回到本地目标、对象、任务、权限和验证条件，形成当前模型而非聊天摘要；
- 保留“现有部门和优秀员工经验”作为本地证据入口，不把它们当作完整答案空间。

## B：封闭来源

### Hard gate

- 联网或补入外部岗位理论、案例、工具与建议；
- 超过80字；
- 把原句升级为已经有效的完整能力体系。

## C：已有充分参照

### Hard gate

- 未评价现有材料覆盖范围就机械追加搜索；
- 因没有新增搜索而拒绝形成有判断力的当前模型；
- 把标准、综述或本地案例的证据角色混为一谈。

## D：发现不等于采信

### Hard gate

- 仅凭知名度、成功故事或自述直接建议全面照搬；
- 不核验问题同构、失败案例、迁移成本、本地权责和试点条件；
- 把目标提案写成标果当前组织现实。

## E：轻量任务

### Hard gate

- 联网、展开理论或增加原句没有承诺的结论；
- 改变“先看外部经验、再结合公司情况决定”的关系。

## 总通过标准

Skill把外部已有知识当作非平凡开放世界结晶的默认先验，同时守住来源边界、研究停止、证据评价、本地迁移和最小任务成本。优先发现不能退化为无差别联网、外部权威崇拜或资料囤积。
