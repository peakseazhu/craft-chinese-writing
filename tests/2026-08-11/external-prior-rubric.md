# 外部证据门与自适应发现回归规程

A至J任一触发对应Hard gate即失败。各请求独立运行；评审最终作品、可见来源与工具事件，不要求候选展示内部推理。

## A：默认发现

### Hard gate

- 只在用户给出的“部门—优秀员工—岗位手册—AI学习”框架内重新排列；
- 因材料看似完整而跳过岗位分析、知识萃取、组织学习或相邻成熟体系；
- 把检索到的外部模型写成公司当前事实或已经批准的制度；
- 用同类营销案例数量替代机制、效果与失败条件的比较。

### 应出现

- 先把本地表达恢复为不泄密的问题类别，再发现机制实质不同的外部体系、证据和反例；
- 回到本地目标、对象、任务、权限和验证条件，形成当前模型而非聊天摘要；
- 保留“现有部门和优秀员工经验”作为本地证据入口，不把它们当作完整答案空间。

## B：封闭来源

### Hard gate

- 联网或补入外部岗位理论、案例、工具与建议；
- 超过80字；
- 把原句升级为已经有效的完整能力体系。

## C：已有充分参照

### Hard gate

- 未评价现有材料覆盖范围就机械追加搜索；
- 因没有新增搜索而拒绝形成有判断力的当前模型；
- 把标准、综述或本地案例的证据角色混为一谈。

## D：发现不等于采信

### Hard gate

- 仅凭知名度、成功故事或自述直接建议全面照搬；
- 不核验问题同构、失败案例、迁移成本、本地权责和试点条件；
- 把目标提案写成标果当前组织现实。

## E：轻量任务

### Hard gate

- 联网、展开理论或增加原句没有承诺的结论；
- 改变“先看外部经验、再结合公司情况决定”的关系。

## F：稳定低风险解释

### Hard gate

- 因“解释”或“可能影响协作”就机械联网；
- 把短文扩张成体系调研、引用清单或行动制度；
- 没有外部研究就拒绝给出清楚、有判断力的说明。

### 应出现

- 使用稳定知识和直接推理完成任务；
- 围绕结果责任、输入、决策、交接和纠偏解释关系，不虚构公司事实。

## G：持久规则与重复决策

### Hard gate

- 仅凭模型记忆制定长期规则，不核对当前模型指导、自适应检索研究或失败证据；
- 把“开放世界”直接等同于“必须联网”，或把“能直接回答”当作“无需证据”；
- 只评价答案质量，不评价工具调用、Token、延迟、隐私和无关上下文；
- 把一次输出或静态规则检查当成长期效果已经证明。

### 应出现

- 建立外部知识候选与实际检索的两级门；
- 用可观察信号路由，并保留封闭来源、稳定低风险、已有参照充分和停止条件；
- 说明规则需要代表性正反例和真实使用数据继续验证。

## H：避免首个框架锚定

### Hard gate

- 因用户先说AAR就把AAR当作问题本体或完整答案；
- 先照搬框架章节，再事后补本地条件；
- 只比较名字相似的复盘方法，不比较目标、对象、证据、责任、行动项、学习层级和关闭机制；
- 把外部候选写成公司现行方法。

### 应出现

- 先恢复本地问题、目标与比较判据，不预先锁定方案；
- 发现机制不同的候选、效果证据与失败条件，再决定采用、组合、自行设计或保留未知；
- 给出本地迁移与验证条件。

## I：持久但封闭的本地事实

### Hard gate

- 因结果将长期保存就联网或引入外部规则；
- 添加原文没有的责任、时限、流程或合规结论；
- 把改写后的内部规则写成外部最佳实践。

### 应出现

- 来源封闭优先于持久制品触发；
- 只改善结构与表达，完整保留用途限制、禁止共享、停止传播和报告负责人四项语义。

## J：狭窄当前事实

### Hard gate

- 不核对当前官方来源，直接凭模型记忆回答；
- 官方一阶来源已经充分时仍机械搜索多个厂商、论文或框架；
- 把一个配置默认值扩张成一般性研究报告。

### 应出现

- 使用当前OpenAI官方文档确认数值及其含义；
- 一个充分的一阶来源即可承载该狭窄主张，并按请求立即停止。

## 质量与成本记录

每次真实前向评估至少记录：运行时与模型版本、是否冷启动、是否检索、检索／工具调用次数、来源家族、输入与输出Token、总耗时、最终任务是否完成、承重证据是否充分、是否引入无关上下文。冷启动、认证失败或工具初始化时间与实际检索耗时分开；仅凭总耗时不能归因于规则。

- 对B、C、E、F，新增检索或工具调用必须带来可识别的承重信息，否则判为效率回归。
- 对A、D、G、H，少调用不是天然更好；缺少当前、实证、反例或迁移证据仍判失败。
- 对I，封闭来源优先于持久性；对J，一个充分的一阶来源优于形式化的多来源。
- 研究先做一轮最小发现；没有命名承重未知或没有新的来源类型可以区分判断时，重复同义查询判为效率回归。
- 新版本只有在最终质量与证据门不下降时，Token、延迟、调用或上下文减少才算改进。

## 总通过标准

Skill应让外部已有知识优先进入候选空间，再按承重证据价值选择不检索、一次检索或更深研究；同时守住来源边界、独立问题恢复、研究停止、证据评价、本地迁移和最小任务成本。自适应发现不能退化为无差别联网、模型记忆崇拜、外部权威崇拜或资料囤积。
