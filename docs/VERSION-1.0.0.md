# v1.0.0

`v1.0.0` 保存 2026-08-06 本轮最新优化之前的完整 `craft-chinese-writing`。

## 版本定位

该版本已经完成整体架构整理，并综合比较 `human-writing`、`humanizer-chinese`、`humanizer` 与中国古代文论、文章学中的可执行原则。它是随后吸收 `human-writing v1.1.0` 新增内容之前的基线，因此适合作为差异评估和可靠回退点。

## 已具备能力

- 以用户任务、材料边界和读者用途为先，不以“去 AI 味”替代写作目标。
- 区分事实、来源主张、推断、未知与作者责任。
- 支持非虚构起草、重构、改写、编辑、声音匹配和保守诊断。
- 按需加载现实写作、文体路由、中文成文校准、诊断、理论基础与古典技法。
- 不从文风反推作者身份，不以单一禁词或统计指标判断文本质量。
- 在没有可定位故障时要求逐字返回原文。
