# v2.2.0：从结晶结果前移到答案空间路由

`v2.1.0` 已经修复两类下游故障：把探索性表达照搬进成品，以及默认把对话过程做成长期来源。后续真实任务暴露出更靠前的问题：如果写作者只在用户给出的材料内部推理，即使能够独立重组，也可能错过世界上已经存在的成熟问题模型；用户只有在后来想到并明确要求外部研究时，答案质量才会提高。

`v2.2.0` 把修复前移到任务入口。

## 主要变化

1. 将写作操作、处理深度与来源模式分开。来源模式包括封闭来源、开放世界和混合来源。
2. 在开放世界或混合来源的高价值结晶任务中，用户不必先声明自己的想法不成熟。Skill 会把输入视为起始观测，恢复通用问题类别，再判断成熟体系是否会改变当前模型。
3. 增加有界发现门：使用不暴露敏感信息的抽象问题，优先一阶来源，比较少量不同机制、反例、失败方式和迁移条件；新增来源不再改变模型时停止。
4. 本地事实、决定、亲历和引语仍受原证据约束。外部模型只能进入解释或提案，不能被写成用户或组织当前事实。
5. 移除“未经授权不得扩大来源集”这一过宽表述。封闭来源仍不可扩大；开放世界研究则受任务、隐私与停止条件约束。

## 没有做什么

- 没有把所有写作任务都改成联网研究。低风险直接写作、逐字处理和明确限定来源的任务仍走最轻路径。
- 没有把“高熵”做成需要长期保存的输入标签或对话分类系统。
- 没有把某个外部框架规定为统一答案。成熟体系只提高候选模型质量，最终仍须由任务材料和现实校准。
- 没有新增第二份 Skill 源码；`skill/` 仍是唯一运行正本。

## 回归覆盖

[`tests/2026-08-10/task-mode-routing-requests.md`](../tests/2026-08-10/task-mode-routing-requests.md) 覆盖三类相反任务：用户没有声明输入不成熟的开放世界结晶、公司事实封闭而解释模型开放的隐私敏感混合任务，以及明确禁止外部研究的封闭来源摘要。配套规程检查主动问题恢复、成熟体系发现、隐私安全、本地事实边界、迁移边界和封闭来源保真。
