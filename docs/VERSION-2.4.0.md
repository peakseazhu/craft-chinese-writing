# v2.4.0：外部知识优先进入候选，检索按证据价值自适应

`v2.3.0`修复了只在本地高熵输入中推演的问题，但把“形成新分类、解释、方案或建议”直接设成实际检索触发，范围仍然过宽。它还用“先检索、后发明”表达顺序，容易把外部知识是默认候选、实时检索是取证工具、模型独立恢复问题与判据三件事混在一起。

`v2.4.0`把这条链拆成两级外部证据门。

## 主要变化

1. 所有开放世界与混合结晶先恢复问题类别、约束和比较判据，不把用户原始分类或首个外部框架锁成答案。
2. 外部已有知识默认进入候选空间；模型已有的稳定知识可生成候选和检索词，但不能代替需要核验的当前证据。
3. 只有出现可观察信号时才实际检索：用户要求当前／最佳／成熟体系或外部比较；承重主张易变、陌生、争议、高影响或需要实证；结果将成为长期模型、规则、Skill、组织／系统设计或重复决策；现有资料冲突或不足。
4. 封闭来源优先于持久制品等检索触发；其余任务在触发信号不存在，或已有高质量参照充分覆盖承重主张时，不为形式完整追加检索。
5. 外部发现继续服从来源质量、问题同构、反例、本地校准和停止条件；狭窄官方状态由一个充分的一阶来源支持时即可停止，不机械凑来源家族。
6. 回归同时评价工具调用、Token、延迟和无关上下文，避免把资料数量当成质量。

## 为什么这样改

外部经验能扩大答案空间，实时检索也会增加延迟、成本、噪音和首因锚定。自适应检索研究表明，不同任务应在不检索、一次检索与更深研究之间路由；OpenAI当前模型建议也要求用代表性任务同时比较成功率、证据、Token、延迟与成本，并减少重复指令。目标不是少检索或多检索，而是让每次检索承担可说明的证据工作。
