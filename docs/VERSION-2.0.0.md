# v2.0.0

`v2.0.0` 以 `v1.0.0` 为可回退基线，吸收 `human-writing v1.1.0` 中经第一性原理筛选后适合通用中文非虚构写作的部分，并根据新旧版本交叉测试修复了实际暴露的逐字保真故障。

## 为什么升级

`human-writing v1.1.0` 新增了几类有价值的观察：翻案腔应按修辞动作而非固定字面诊断；材料中真实发生的认识变化不能为了“去句式”而被抹掉；“进行了优化”“实现了提升”一类名词化应还原为人和动作；句长、连词和同构句式可以帮助定位问题。

这些观察适合吸收，但原项目同时包含全局标点限制、真实引语命中禁令时改成转述、三项排比上限、固定句长和“删除一半连词”等规则。它们与通用非虚构写作中的技术字面量、政策条件、作者原话、文体差异和保守编辑契约冲突，因此没有合并。

## 第二版具体变更

### 1. 按语义动作诊断虚假翻案

- 判断是否先给读者或“大家”安上没有材料依据的误解。
- 判断否定动作是否只用于给普通结论制造顿悟感。
- 判断后半句附近是否真正出现了新证据。
- 没有真实认知变化时，直接给判断和依据，不通过换一套字继续翻案。

### 2. 保留真实的认识修正

当材料明确记录某个团队、作者或来源原先怎样判断，后来被哪条证据修正时，保留“谁改变了认识、什么证据促成改变”的事实过程。第二版不会因为某种句式常被滥用，就把真实的证据更新删掉。

### 3. 把名词化还原为行动

遇到“完成了对流程的优化”“实现了质量提升”等表达，优先恢复行动者、直接动词和可核结果。材料没有结果数字时，不为了让句子具体而补造效果。

### 4. 把统计特征降为线索

句长离散程度、连词密度、同构句式次数和自造引号短语只用于定位可疑段落，不能单独证明文本存在问题，也不设置跨文体统一阈值。

### 5. 强化逐字返回

测试发现新旧版本都会偶发把“4 月”重打成“4月”。第二版把原有“无可定位问题则逐字返回”变成可执行门槛：复制源文本，不重新输入或规范化；交付前进行字面比较；空格、标点、引号、大小写和 Markdown 的任何改变都算失败。

### 6. 控制上下文成本

新增内容只保留一条核心原则和必要的诊断、校准示例。中间版本曾加入不会改变行为的参考页目录，正式版已删除。相对 `v1.0.0`，运行包最终只改动三个文件，共 27 行新增、6 行删除或替换。

## 测试结果

- 14 题历史回归：`v2.0.0` 96.000，`v1.0.0` 96.393；两版均 14/14 通过硬约束。
- 8 题全新首轮：`v2.0.0` 98.250，`v1.0.0` 98.375；实质平局。
- 8 题、三次重复、两名盲评者：`v2.0.0` 97.729、24/24；`v1.0.0` 95.833、23/24。
- 将旧版一次逐字失败的硬惩罚仅用于敏感性分析而还原后，两版为 97.729 与 97.708，只差 0.021。
- 最终逐字修正：6 种文本、三次独立运行 18/18；两次混合任务 2/2，总计 20/20 逐字符一致。

测试说明第二版没有得到“全面提高平均文笔”的证据。升级理由是增加了合理、可迁移的故障覆盖，并对已经复现的逐字漂移给出直接修正，而不是追求不可复现的微小分差。
