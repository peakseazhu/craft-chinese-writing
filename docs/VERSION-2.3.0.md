# v2.3.0：先发现外部已有知识，再决定是否发明

`v2.2.2`已经能够把高熵输入恢复为开放世界问题，也要求在成熟体系可能改变模型时进行研究。但这个触发仍把“可能改变”交给模型预判：输入看起来充分、用户已经给出一套解释，或模型对本地推演过度自信时，外部已有知识仍可能被降成遇到困难后的补救。

`v2.3.0`修复研究触发，不把“外部”本身升级为权威。

## 主要变化

1. 对需要形成新问题分类、解释模型、方案或会改变判断与行动的建议的开放世界与混合结晶，在列提纲前默认做一次有界外部发现。
2. 用当下可观察的任务产物触发研究，不再用“材料是否不足”或“成熟体系也许有用”作为代理条件。
3. 保留两个明确的无需追加条件：来源边界已经封闭，或现有高质量外部参照已覆盖承重主张。
4. 继续按主张选择来源、比较不同机制、回到本地证据校准，并在新增来源不再改变判断时停止。
5. 明确优先发现不等于优先相信、照搬、长期保存，也不能提高本地事实的证据等级。

## 没有做什么

- 没有要求忠实改写、封闭摘要、简单校对和稳定常识任务一律联网。
- 没有把知名机构、热门案例或“最佳实践”当作高质量证据。
- 没有要求把检索结果、会话过程或互联网内容全量沉淀为知识库。
- 没有阻止本地创新；外部基线不适配时，仍可形成新方案，但要保留比较、迁移条件与验证边界。
